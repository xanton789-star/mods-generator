Modrinth · Fabric

Fabric Modpack Generator

Cari mod dari Modrinth, pilih yang cocok dengan versi Minecraft dan Fabric Loader kamu, lalu unduh semuanya sebagai satu file mods.zip.

1. Atur versi game

Hanya versi Minecraft yang tersedia di Modrinth.
Pilih versi loader yang benar-benar terpasang. Generator juga akan memeriksa syarat versi loader di dalam setiap file mod.
Mengambil daftar versi dari layanan resmi Modrinth dan Fabric...

2. Cari dan pilih mod

Hasil pencarian disaring berdasarkan Minecraft dan Fabric. Saat ZIP dibuat, setiap file JAR diperiksa untuk syarat minimum/maksimum Fabric Loader. Tekan Enter untuk mencari.
Pilih versi Minecraft dan Fabric Loader, lalu cari mod.
Generator akan memilih rilis terbaru yang benar-benar cocok dengan versi Minecraft dan Fabric Loader pilihanmu. Jika rilis terbaru terlalu baru, generator akan mencoba rilis sebelumnya.

Catatan: generator ini menggunakan API Modrinth dan Fabric secara langsung. Koneksi internet diperlukan. Mod yang memiliki dependensi wajib mungkin memerlukan mod tambahan; periksa halaman masing-masing mod sebelum bermain. File ZIP tidak memasang mod secara otomatis—sebelum menyalin isinya, kosongkan/pindahkan dulu mod lama dari folder .minecraft/mods agar versi lama tidak ikut terbaca.
